# FlexiFit Pro - Web Frontend Dokümantasyonu
**Canlı Uygulama Adresi:** https://haribulbul-adil-mammadov.vercel.app
YouTube linki-[https://youtu.be/iUbSTOnaI1o?si=NcxtU7SOTj52N1f3]

### Proje Detayları
- **Teknolojiler:** HTML5, Tailwind CSS, Vanilla JavaScript.
- **Mimari:** REST API mimarisine uygun olarak Render backend ile tam entegre çalışmaktadır.
- **Responsive Tasarım:** Uygulama mobil öncelikli (Mobile-First) olarak tasarlanmış olup tüm cihazlarla uyumludur.

### Gerçekleştirilen Fonksiyonlar
1. **Kullanıcı Paneli:** MongoDB'den gelen anlık verilerle profil ve kalori takibi.
2. **Dinamik Listeleme:** Fetch API kullanılarak asenkron veri çekme ve silme işlemleri.
3. **AI Coach:** Backend üzerindeki mantıksal katman ile kullanıcıya özel öneri sistemi.
